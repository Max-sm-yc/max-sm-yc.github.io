Inference / C++ / Autonomous Research+

Embedding Gemma 2 — Mask Fast Path

An autonomous optimization loop uncovered an attention-mask bottleneck in llama.cpp. Built a layout-aware fast path that replaces per-pair checks with contiguous bulk fills.

Up to −38.71% latency / 14.67× mask speedup
Approach

Profiled Embedding Gemma 2 workloads through an autonomous research loop and identified CPU attention-mask construction as a disproportionate cost. For eligible contiguous sequence layouts, computed each query row's allowed key interval directly instead of checking every query/key pair, then filled the interval in bulk. An eligibility-gated fallback preserves the general mask path for unsupported layouts.

−38.71%Largest measured end-to-end latency reduction (L4096/B1)
14.67×Fastest mask generation relative to baseline (L1024/B1)
